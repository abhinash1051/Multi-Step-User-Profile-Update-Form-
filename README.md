# Multi-Step User Profile Form

A full-stack application where users complete a multi-step form to create their profile, including uploading a photo, choosing country/state/city, and selecting subscription plans.

---

## 🚀 Features

- Multi-step React form
- Profile photo upload
- Dynamic country, state, and city dropdowns
- Password strength checker
- Username availability check
- Backend API with Express.js
- CORS-enabled for frontend-backend communication
- Data submission with FormData

---

## 🛠️ Tech Stack

- **Frontend:** React, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (optional, depending on how you implement it)
